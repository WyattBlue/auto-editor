---
title: cache
---

The `cache` command stores the `audio` and `motion` levels, saving time at the cost of space. It keeps up to 255 entries, deleting the oldest past that.


## Examples
To list the cache files:

```sh
auto-editor cache
```

To remove the cache files (`clean` works too):

```sh
auto-editor cache clear
```
